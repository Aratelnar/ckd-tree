## Как собрать:
1. Потребуется [.NET10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
2. Запустить `dotnet build`

## Как проверить: 

Текущая реализация упакована в dll и используется в тестах.
Чтобы запустить тесты нужно выполнить команду `dotnet test`

## Устройство проекта:

### `I2DTree.cs`
Содержит интерфейс, описывающий структуру Kd-дерева, а также методы расширения с алгоритмами запросов к дереву.

### `2DTree.cs`
Содержит реализации iKd-дерева и cKd-дерева, а также алгоритмы их посторения

### `DirectAccessCodes.cs`
Содержит реализацию структуры данных Directly Accesseble Codes, необходимую для cKd-дерева

Все реализации не зависят от типа используемых чисел для координат и могут работать с любым встроенным целочисленным типом данных
